# python-learning

Коллекция моих учебных проектов и скриптов на Python.

## Что тут есть:
- `api-client.py` — универсальный клиент для API. Умеет делать GET-запросы, ловить таймауты, обрывы связи и HTTP-ошибки.
- `json_processor.py` — работа с JSON-файлами. Чтение, изменение и перезапись с обработкой ошибок.
